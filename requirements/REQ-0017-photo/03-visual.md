## F-34: Визуальное представление фотографии

Фотография имеет визуальные представления в духе старой фотографии/полароида, согласованные со стилистикой фотоаппарата ([REQ-0013](../REQ-0013-vintage-camera/README.md)).

### 3D-модель в игровой зоне (InWorld)

В дополнение к [F-16](../REQ-0012-base-item/04-visual.md):

| Свойство | Значение |
|----------|----------|
| Форма | Фото-карточка (полароид): прямоугольный картон с кадром и светлым полем; читается как «лежащая фотография» |
| Размер | Как базовый предмет: умещается в ячейке (3.6 × 3.6), ощутимо меньше персонажа |
| Размещение | На полу (Y ≈ 0), как выброшенный предмет ([REQ-0014](../REQ-0012-base-item/REQ-0014-base-item-item-in-world/README.md)) |
| Ориентация | Произвольная на полу |
| Ассет | TBD (допустим плейсхолдер) |

### Живое окно вида «сквозь фото» и индикатор входа

Пока фотография активирована, **по центру экрана** (как видоискатель фотоаппарата) показывается **живое окно** вида запечатлённой точки — **не статичный снимок**: если в этот момент в том месте что-то движется (например, проходит монстр), это видно в окне. По мере накопления входа ([F-33](./02-teleport-logic.md)) окно **растёт** из центра, подводя к переносу.

**Фотография «оживает» при входе.** Вход — это не просто увеличение окна: по мере продвижения фотография **оживает за счёт освещения**. В начале (прогресс 0) вид тускло подсвечен — «спящий» снимок; по мере входа освещённость внутри окна **нарастает**, и сцена «загорается», будто игрок уже вступает в запечатлённую точку. К моменту переноса свет в окне уже соответствует свету «на месте», поэтому телепортация не даёт резкого скачка яркости.

| Параметр | Значение |
|----------|----------|
| Что показывает | Живой вид запечатлённой точки + близость к срабатыванию (0 → `EnterDuration`) |
| Расположение | По центру экрана, единообразно с видоискателем фотоаппарата |
| Обрамление | **Простая рамка «под старину»** (тёмное дерево + латунный кант) вокруг живого вида — как у видоискателя фотоаппарата |
| Визуальные ориентиры | Окно в центре растёт от небольшого к почти полноэкранному по мере входа |
| Тон | **Полноцветное изображение** — без монохрома и сепии |
| Оживание освещением | Освещённость внутри окна **растёт с входом** (0 → 1): тускло-«спящий» снимок → полностью освещённая «живая» сцена. Это же убирает резкий скачок света при переносе |
| При сбросе прогресса | Окно уменьшается обратно и **тускнеет**; при деактивации/выбросе — исчезает |

> Обрамление окна единообразно с видоискателем фотоаппарата ([F-21](../REQ-0013-vintage-camera/01-viewfinder-ui.md)): та же рамка «под старину». В отличие от видоискателя, вид в фотографии **полноцветный** (монохром/сепия убраны).

Точная реализация эффекта — на этапе проработки; первый проход может быть простым (например, тонкий индикатор-полоса + лёгкая виньетка).

### Переход перемещения (маскировка подгрузки чанков)

Так как точка перемещения может быть далеко от текущей позиции, после срабатывания нужен визуальный переход, скрывающий кратковременную подгрузку чанков (стриминг, [TECH_SPEC §5.2](../TECH_SPEC.md)):

| Параметр | Значение |
|----------|----------|
| Идея | **Лёгкое жёлтое мерцание экрана** в момент перехода: несколько быстрых всплесков полупрозрачного тёплого жёлтого света, затухающих к концу перехода, скрывающих смену сцены |
| Длительность | Короткая, достаточная, чтобы скрыть появление чанков |
| Прозрачность | Свет **лёгкий/прозрачный** — картинка не уходит в полную заливку, экран лишь подсвечивается |
| Стиль | Согласован с фото-темой (вспышка затвора / проявление снимка) |
