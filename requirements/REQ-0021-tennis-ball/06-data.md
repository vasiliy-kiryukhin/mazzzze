# Теннисный мячик — Параметры по умолчанию (Data)

> **Фича:** REQ-0021-tennis-ball · **Тип документа:** требования, грань «данные» (WHAT, без деталей реализации)

Конкретные значения параметров мячика. Числа — по умолчанию; калибруются при реализации (аналогично `TickSeconds`/`FocusMinDistance` в [REQ-0013](../REQ-0013-vintage-camera/design.md)).

## Идентичность и модель

| Параметр | Умолчание | Смысл |
|----------|-----------|-------|
| Идентификатор типа | `tennis_ball` | Ключ типа предмета |
| Отображаемое имя | «Теннисный мячик» | UI/инвентарь |
| Паттерн использования | B (Activated) | Активация «в руку» |
| Расходуемость | нет (многоразовый) | Бросок не уничтожает |
| Путь к 3D-модели | `art/base_ball.glb` | Модель в мире/руке/снаряде |
| Размер в мире | (доля от роста игрока; ≈ как у прочих предметов) | Масштаб модели `WorldItem` |

## Зарядка и бросок ([F-48](./02-throw-logic.md), [F-50](./04-input.md))

Экспорты в `InventoryHud` (калибруются в инспекторе).

| Параметр | Умолчание | Смысл |
|----------|-----------|-------|
| MinThrowForce | 5.0 м/с | Сила броска при тапе / минимуме заряда |
| MaxThrowForce | 11.0 м/с | Сила при полном заряде (умеренно: коридор узкий, 3.6 м) |
| MaxChargeTime | 1.0 с | Время выхода на максимальную силу; далее плато |
| ThrowUpwardBias | 3.0 м/с | Вертикальная составляющая начальной скорости (формирует дугу) |
| MoveSpeedFactorWhileCharging | 0.45 | Множитель скорости ходьбы во время заряда |
| BallSize | 0.2 м | **Единый** физический размер мяча: рука = снаряд = лежащий предмет (иначе мяч «прыгал» бы в размере при приземлении) |

## Физика снаряда ([F-48](./02-throw-logic.md))

Константы в `ThrowProjectile` (`CharacterBody3D`, кинематический `MoveAndCollide`).

| Параметр | Умолчание | Смысл |
|----------|-----------|-------|
| Gravity | 15.0 м/с² | Ускорение вниз — **в темпе игры** (как `Player.Gravity`), не движковые 9.8 |
| Restitution | 0.5 | Доля нормальной скорости после отскока |
| ImpactFriction | 0.06 (кап 0.35) | Потеря касательной скорости, пропорциональна силе удара |
| LinearDamp | 0.8 /с | Мягкое гашение (докатывание/воздух) |
| GroundFriction | 5.0 /с | Трение качения на полу — мяч уверенно останавливается, а не «ползёт» на пороге |
| StopThreshold | 0.9 м/с | Порог скорости «считается остановившимся» |
| StopTime | 0.2 с | Сколько времени скорость ниже порога → переход в `WorldItem` |
| MaxAirborneTime | 6.0 с | Принудительная остановка (предохранитель) |
| HitRadiusPad | 0.4 м | Запас к радиусу мяча для засчёта попадания в тело монстра |

## Воздействие на монстра ([F-49](./03-monster-effect-logic.md))

| Параметр | Значение | Смысл |
|----------|-----------|-------|
| StunDuration | живёт в монстре (`Monster.StunDuration`, у ифрита 2.5 с) | Длительность стана при прямом попадании; мяч лишь инициирует `Stun()` |
| Отвлечение | штатное поведение `Distract` монстра | Монстр доходит до мяча (`DistractReachRadius`) и возвращается в `Cycle` |

> Мяч не хранит своих `StunDuration`/`InspectDuration`/`InspectRadius`: стан и отвлечение целиком обслуживает шаблон монстра ([REQ-0019/F-41](../REQ-0019-base-monster/01-states-logic.md)). Мяч лишь вызывает `Stun()` (прямое попадание «видевшего бросок») и ложится как `WorldItem`, который монстр сам замечает для отвлечения.
