# 50 — Визуальное представление (F-34)

> **Покрытие:** [F-34](../../requirements/REQ-0017-photo/03-visual.md)
> **Что проверяем:** живое окно вида запечатлённой точки по центру экрана, его рост с
> прогрессом входа, уменьшение при сбросе, исчезновение при деактивации/выбросе;
> «оживание» освещением, полноцветный рендер, рамка «под старину», жёлтое мерцание
> при телепорте.
>
> **Тип всех TC в этом файле:** визуал/модель (требуют скриншотов, не автоматизированы в JSON).
>
> Окружение/запуск/ввод — см. [00-environment.md](./00-environment.md).

---

### TC-VIS-01: При активации появляется живое окно по центру экрана

**Покрытие:** F-34 (окно вида) · **Тип:** визуал

**Предусловия:** фотография создана. Инвентарь закрыт.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Сразу сделай скриншот.

**Ожидаемый результат:**
- По центру экрана видно небольшое прямоугольное окно с живым видом запечатлённой точки.
- Вид полноцветный (не монохром/сепия), в реальном времени.
- Вокруг окна — простая рамка: тёмное дерево + латунный кант.

**Верификация:**
- Визуал: скриншот `/tmp/tc-vis-01-window.png` — окно по центру, вид запечатлённой точки (те же стены/коридор, что были при съёмке), рамка «дерево+латунь».
- Визуал: в окне **нет** монохрома/сепии — цвета естественные.

### TC-VIS-02: Окно растёт с прогрессом входа

**Покрытие:** F-34 (рост окна) · **Тип:** визуал

**Предусловия:** фотография активирована (TC-VIS-01). Инвентарь закрыт. Игрок смотрит в открытый коридор.

**Шаги:**
1. Сделай скриншот до начала движения.
2. Начни движение вперёд: `xdotool keydown w`.
3. Через ~0.7 с (середина прогресса) — скриншот.
4. Прямо перед телепортом (~1.2 с) — скриншот.

**Ожидаемый результат:**
- На скриншотах видно, как окно растёт: от `WindowWidthMin=0.22` (мелкое в центре) → среднее (0.5) → почти на весь экран `WindowWidthMax=0.85` (перед переносом).
- Рост равномерный, пропорциональный Progress (0 → 1).

**Верификация:**
- Визуал: серия скриншотов (`/tmp/tc-vis-02-progress-*.png`) показывает увеличение ширины окна.

### TC-VIS-03: При сбросе прогресса окно уменьшается обратно

**Покрытие:** F-34 (сжатие окна при сбросе) · **Тип:** визуал

**Предусловия:** фотография активирована. Инвентарь закрыт. Коридор открыт.

**Шаги:**
1. Начни движение вперёд и держи ~0.8 с (окно выросло).
2. Отпусти «вперёд» (`xdotool keyup w`).
3. Сразу сделай скриншот — окно должно уменьшиться.

**Ожидаемый результат:**
- После отпускания окно уменьшается обратно к начальному размеру `WindowWidthMin` (или близко к нему — мгновенный возврат при Progress=0).

**Верификация:**
- Визуал: скриншот `/tmp/tc-vis-03-shrink.png` — окно маленькое в центре после отпускания (Progress=0).

### TC-VIS-05: Жёлтое мерцание экрана при телепорте

**Покрытие:** F-34 (жёлтый переход, маскировка подгрузки чанков) · **Тип:** визуал

**Предусловия:** фотография активирована. Игрок смотрит в открытый коридор.

**Шаги:**
1. Начни движение вперёд и **сразу** делай серию быстрых скриншотов в момент телепорта:
   ```bash
   xdotool keydown w && sleep 1.0 && for i in 1 2 3 4 5; do import -window root /tmp/tc-vis-05-flash_$i.png; sleep 0.1; done && xdotool keyup w
   ```

**Ожидаемый результат:**
- В момент телепорта экран **подсвечивается** жёлтым светом.
- Мерцание **лёгкое** (прозрачное, не заливает экран целиком) — `FlashMaxAlpha=0.35`.
- 3 быстрых всплеска (синусоида `FlashFlickers=3`), затухающих к концу (общая длительность `FlashDuration=0.6` с).

**Верификация:**
- Визуал: на серии скриншотов видно жёлтое свечение поверх экрана, которое появляется и затухает за ~0.6 с.

### TC-VIS-06: Освещение в окне нарастает с прогрессом входа («оживание»)

**Покрытие:** F-34 (ambient-заливка от Progress) · **Тип:** визуал

**Предусловия:** фотография активирована. Инвентарь закрыт. Коридор открыт.

**Шаги:**
1. Сделай скриншот до начала движения (Progress=0, заливка `AmbientEnergyMin=0.2` — тускло).
2. Начни движение вперёд и через ~1.0 с (Progress≈0.7) — скриншот.
3. Прямо перед телепортом (~1.3 с, Progress≈1.0) — скриншот.

**Ожидаемый результат:**
- На скриншотах видно, как освещённость внутри окна **нарастает**: от тусклого «спящего» снимка → до полностью освещённой «живой» сцены при Progress=1.0.
- Заливка тёплая (цвет под `HeadLight` игрока — `1, 0.96, 0.86`).
- К моменту телепорта свет в окне уже соответствует свету «на месте» — нет резкого скачка яркости.

**Верификация:**
- Визуал: серия скриншотов (`/tmp/tc-vis-06-ambient-*.png`) — яркость окна растёт от тёмного к светлому.

**Верификация:**
