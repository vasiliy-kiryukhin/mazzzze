# 30 — Вход движением вперёд и телепорт (F-33)

> **Покрытие:** [F-33](../../requirements/REQ-0017-photo/02-teleport-logic.md)
> **Что проверяем:** накопление/сброс прогресса входа, условие «реального продвижения»,
> срабатывание телепорта по достижении `EnterDuration`, уничтожение фотографии после входа,
> освобождение слота.
>
> Окружение/запуск/ввод — см. [00-environment.md](./00-environment.md).

---

### TC-F33-01: Накопление прогресса входа и телепорт (успешный вход)

**Покрытие:** F-33 (накопление прогресса, срабатывание) · **Тип:** логика

**Предусловия:** фотография создана (TC-F31-01). Инвентарь закрыт. Игрок смотрит в открытый коридор.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Удерживай «вперёд»: `xdotool keydown w && sleep 2.5 && xdotool keyup w`.

**Ожидаемый результат:**
- После непрерывного продвижения вперёд в течение ~1.33 с **реального** движения (EnterDuration) происходит мгновенный перенос.
- Игрок оказывается в запечатлённой точке (на полу, как при спавне).
- Камера повёрнута в запечатлённое направление.
- Фотография уничтожена, слот 0 свободен.
- На экране — короткое жёлтое мерцание.

**Верификация:**
- Консоль: `[Photo] Entered → teleported` → `[Player] Teleport → world=(…) yaw=… pitch=…`.
- Визуал: жёлтая вспышка на экране; инвентарь — слот 0 пуст.

**JSON:** [TC-F33-01.walk-forward-teleport.json](./TC-F33-01.walk-forward-teleport.json)

### TC-F33-02: Прогресс не растёт у стены (заблокирован вход)

**Покрытие:** F-33 (условие реального продвижения) · **Тип:** логика

**Предусловия:** фотография создана и активирована. Игрок стоит лицом к стене (yaw ≈ 180° от стартового направления).

Рекомендация по setup'у: после активации фото поверни камеру на 180° — там обычно стена за спиной стартовой клетки.

**Шаги:**
1. Активируй фотографию (если ещё не): `i` → `1` → `1` → `i`.
2. Поверни камеру лицом к ближайшей стене (например, `xdotool mousemove -- -300 0` — или `aim_camera yaw_deg:180`).
3. Удерживай «вперёд» длительное время (≥ 4 с): `xdotool keydown w && sleep 4 && xdotool keyup w`.

**Ожидаемый результат:**
- Перенос **не происходит**, несмотря на удержание «вперёд».
- Прогресс входа не накапливается (скорость игрока гасится стеной → `advance ≈ 0 < Speed*0.4`).

**Верификация:**
- Консоль: **нет** маркера `[Photo] Entered → teleported`.
- Консоль: **нет** маркера `[Player] Teleport → world=(…)`.
- Визуал: игрок упирается в стену, не движется.

**JSON:** [TC-F33-02.wall-blocks-entry.json](./TC-F33-02.wall-blocks-entry.json)

### TC-F33-03: Прогресс сбрасывается при отпускании «вперёд»

**Покрытие:** F-33 (сброс прогресса — условие «отпустил вперёд») · **Тип:** логика

**Предусловия:** фотография создана и активирована. Игрок смотрит в открытый коридор.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Удерживай «вперёд» коротко: `xdotool keydown w && sleep 0.8 && xdotool keyup w` (0.8 с < EnterDuration 1.33 с — прогресс не должен завершиться).
3. Пауза: `sleep 0.5` (отпущен «вперёд» — прогресс сброшен).
4. Снова удерживай «вперёд»: `xdotool keydown w && sleep 2.5 && xdotool keyup w`.

**Ожидаемый результат:**
- После первого короткого удержания телепорта нет (прогресс сброшен при отпускании).
- После второго непрерывного удержания (~2.5 с, > EnterDuration) происходит перенос.
- Перенос происходит **только** после второго удержания — прогресс начался с 0 заново.

**Верификация:**
- Консоль: **один** маркер `[Photo] Entered → teleported` — тот, что после второго удержания.
- Между двумя удержаниями в логе **нет** `[Photo] Entered → teleported`.

**JSON:** [TC-F33-03.progress-reset-on-release.json](./TC-F33-03.progress-reset-on-release.json)

### TC-F33-04: Прогресс сбрасывается при деактивации фотографии

**Покрытие:** F-33 (сброс прогресса — условие «деактивация») · **Тип:** логика

**Предусловия:** фотография создана и активирована. Игрок смотрит в открытый коридор.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Удерживай «вперёд» коротко: `xdotool keydown w && sleep 0.8 && xdotool keyup w`.
3. Открой инвентарь (`i`), деактивируй: `1` → `1`, закрой (`i`).
4. Снова активируй: `i` → `1` → `1` → `i`.
5. Удерживай «вперёд»: `xdotool keydown w && sleep 2.5 && xdotool keyup w`.

**Ожидаемый результат:**
- Прогресс первого удержания сброшен деактивацией.
- Телепорт происходит **только** после второго удержания (реактивация + полный EnterDuration).

**Верификация:**
- Консоль (по порядку): `[Inventory] Activate 'photo' → hand` → (удержание 0.8 с, нет телепорта) → `[Inventory] Deactivate 'photo' → slot 0` → `[Inventory] Activate 'photo' → hand` → `[Photo] Entered → teleported`.
- **Ровно один** маркер `[Photo] Entered → teleported`.

**JSON:** [TC-F33-04.deactivate-resets-progress.json](./TC-F33-04.deactivate-resets-progress.json)

### TC-F33-05: Прогресс сбрасывается при выбрасывании активированной фотографии

**Покрытие:** F-33 (сброс прогресса — условие «выброс активированного») · **Тип:** логика

**Предусловия:** фотография создана и активирована. Инвентарь закрыт.

**Шаги:**
1. Удерживай «вперёд» коротко: `xdotool keydown w && sleep 0.8 && xdotool keyup w`.
2. Открой инвентарь (`i`), выброс активированного: `1` → `Shift+1`.
3. Закрой инвентарь (`i`).

**Ожидаемый результат:**
- Прогресс входа сброшен, фотография в мире.
- Телепорта нет.
- Фотография не уничтожена.

**Верификация:**
- Консоль: `[Inventory] Drop 'photo' → world at (x, z)`.
- Отсутствие: **нет** `[Photo] Entered → teleported`.

**Автоматизация:** не автоматизирован (требует модификатора Shift — раннер может не поддерживать).

### TC-F33-06: Прогресс не растёт при движении назад или стрейфе

**Покрытие:** F-33 (условие «реальное продвижение вперёд») · **Тип:** логика

**Предусловия:** фотография создана и активирована. Инвентарь закрыт.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Удерживай «назад» (`S`) длительное время (≥ 4 с): `xdotool keydown s && sleep 4 && xdotool keyup s`.
3. Удерживай «вправо» (`D`) длительное время (≥ 4 с): `xdotool keydown d && sleep 4 && xdotool keyup d`.

**Ожидаемый результат:**
- При движении назад/вправо прогресс не накапливается (проекция скорости на `PlanarCamForward` отрицательна или мала).
- Телепорта **нет** в обоих случаях.

**Верификация:**
- Консоль: **нет** маркера `[Photo] Entered → teleported`.
- Консоль: **нет** маркера `[Player] Teleport → world=(…)`.

**JSON:** [TC-F33-06.no-progress-backward-strafe.json](./TC-F33-06.no-progress-backward-strafe.json)

### TC-F33-07: Точка телепорта совпадает с запечатлённой (позиция)

**Покрытие:** F-33 (корректность координат телепорта) · **Тип:** логика

**Предусловия:** фотография создана (TC-F31-01). Координаты из лога известны.

**Шаги:**
1. Активируй фотографию и войди (удерживай «вперёд» ~2.5 с).

**Ожидаемый результат:**
- Игрок телепортирован в ту же точку, где стоял в момент съёмки.

**Верификация:**
- Консоль: сверить `(x, z)` из `[Camera] Photo created at (…, …)` и `[Player] Teleport → world=(…, …)` — числа совпадают с точностью ~0.1.

**Автоматизация:** не автоматизирован (требует сравнения чисел из capture_group двух маркеров — нужен `compare` для `[Camera] Photo created at (X,…)` vs `[Player] Teleport → world=(X,…)`).

### TC-F33-08: После входа слот освобождается

**Покрытие:** F-33 (очистка слота, F-19a) · **Тип:** логика

**Предусловия:** фотография создана и активирована. Инвентарь закрыт.

**Шаги:**
1. Иди вперёд до телепорта (~2.5 с).
2. После телепорта открой инвентарь (`i`) и проверь слот 0.

**Ожидаемый результат:**
- Слот 0 **пуст** (предмет уничтожен, бронь снята).

**Верификация:**
- Консоль: `[Photo] Entered → teleported`.
- Визуал: скриншот инвентаря — слот ряд 1 / колонка 1 пуст.

**Автоматизация:** покрывается TC-F33-01 (JSON) — assertions включают проверку освобождения слота.
