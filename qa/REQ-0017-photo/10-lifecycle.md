# 10 — Жизненный цикл фотографии (F-31)

> **Покрытие:** [F-31](../../requirements/REQ-0017-photo/README.md)
> **Что проверяем:** свойства предмета (`photo`, паттерн B, одноразовый), все допустимые
> переходы жизненного цикла (создание → InInventory → Activated → уничтожение при входе),
> отличие от нерасходуемого предмета (мяч).
>
> Окружение/запуск/ввод — см. [00-environment.md](./00-environment.md).

---

### TC-F31-01: Фотография создаётся при успешной съёмке

**Покрытие:** F-31 (создание из камеры) · **Тип:** логика

**Предусловия:** свежий запуск игры. Камера засеяна в слот 0.

**Шаги:**
1. Опусти камеру, чтобы смотреть вдоль коридора (не в стену): `xdotool mousemove -- 0 -20`.
2. Открой инвентарь (`i`), выбери слот 0: `1` → `1`, закрой (`i`). Камера в руке.
3. Нажми ЛКМ — видоискатель открыт.
4. Жди ~2.5 с (отсчёт 3→2→1).

**Ожидаемый результат:**
- Фотография создана и помещена в слот 0 (заменяет камеру).
- Игрок проигрывает жест подбора (`Interact`).
- Слот 0 подсвечивается вспышкой (F-30).
- Камера уничтожена.

**Верификация:**
- Консоль: `[Camera] Viewfinder open, countdown start` → `[Camera] Shutter — photo created` → `[Camera] Photo created at (…) yaw=… → slot 0`.
- Визуал: в инвентаре в слоте 0 — иконка-полароид вместо иконки камеры; слот 0 забронирован (выделен).

**Автоматизация:** не автоматизирован (JSON-сетап включает этот flow, но сам TC из-за визуальной проверки сложен для чистого JSON).

### TC-F31-02: Активация фотографии в руку (InInventory → Activated)

**Покрытие:** F-31 (паттерн B активации) + F-19a · **Тип:** логика/модель

**Предусловия:** TC-F31-01 выполнен — фотография создана и лежит в слоте 0. Инвентарь закрыт.

**Шаги:**
1. Открой инвентарь (`i`), выбери слот 0: `1` → `1`.
2. Закрой инвентарь (`i`).

**Ожидаемый результат:**
- Фотография «в руке» — игрок проигрывает жест подбора (`Interact`).
- Слот 0 забронирован (нельзя положить другой предмет).
- По центру экрана появляется **живое окно** вида запечатлённой точки (F-34).
- На миникарте — маркер маяка запечатлённой точки (если реализован).

**Верификация:**
- Консоль: `[Inventory] Activate 'photo' → hand (slot 0 reserved)`.
- Визуал: скриншот — живое окно по центру экрана с видом запечатлённой точки; скриншот инвентаря — слот 0 забронирован.

**JSON:** [TC-F31-02.activate-photo-to-hand.json](./TC-F31-02.activate-photo-to-hand.json)

### TC-F31-03: Деактивация возвращает фотографию в слот (Activated → InInventory)

**Покрытие:** F-31 (переход Activated → InInventory) · **Тип:** логика

**Предусловия:** TC-F31-02 выполнен — фотография активирована. Инвентарь закрыт.

**Шаги:**
1. Открой инвентарь (`i`).
2. Повторно выбери ту же ячейку: `1` → `1` (toggle деактивации).
3. Закрой инвентарь (`i`).

**Ожидаемый результат:**
- Фотография возвращается в забронированный слот 0 (иконка на месте).
- Слот всё ещё забронирован (предмет в нём же).
- Живое окно по центру экрана исчезает.
- Прогресс входа (если был) сброшен.
- Фотография **не уничтожается**.

**Верификация:**
- Консоль: `[Inventory] Deactivate 'photo' → slot 0`.
- Отсутствие: **нет** строк `[Photo] Entered → teleported`.
- Визуал: живое окно исчезло.

**JSON:** [TC-F31-03.deactivate-photo.json](./TC-F31-03.deactivate-photo.json)

### TC-F31-04: Фотография не уничтожается при деактивации (можно активировать повторно)

**Покрытие:** F-31 (сохранность после цикла активация→деактивация) · **Тип:** логика

**Предусловия:** TC-F31-03 выполнен — фотография деактивирована, лежит в слоте 0.

**Шаги:**
1. Открой инвентарь (`i`), выбери слот 0: `1` → `1`.
2. Закрой инвентарь (`i`).
3. Открой инвентарь снова (`i`), повторно выбери слот 0: `1` → `1` (деактивация).
4. Закрой инвентарь (`i`).

**Ожидаемый результат:**
- Фотография активируется, затем деактивируется — оба цикла успешны.
- Лог содержит **две** активации и **две** деактивации подряд.
- Фотография не уничтожается (слот 0 не освобождается в смысле «нет предмета»).

**Верификация:**
- Консоль (по порядку): `[Inventory] Activate 'photo' → hand (slot 0 reserved)` → `[Inventory] Deactivate 'photo' → slot 0` → `[Inventory] Activate 'photo' → hand (slot 0 reserved)` → `[Inventory] Deactivate 'photo' → slot 0`.
- Отсутствие: **нет** `[Photo] Entered → teleported`.

**JSON:** [TC-F31-04.activate-deactivate-cycle.json](./TC-F31-04.activate-deactivate-cycle.json)

### TC-F31-05: Фотография уничтожается после входа (одноразовая)

**Покрытие:** F-31 (одноразовость: Activated → уничтожение) · **Тип:** логика

**Предусловия:** TC-F31-01 выполнен — фотография в слоте 0. Инвентарь закрыт.

**Шаги:**
1. Активируй фотографию: `i` → `1` → `1` → `i`.
2. Убедись, что впереди открытый коридор (не стена).
3. Иди вперёд: `xdotool keydown w && sleep 2.5 && xdotool keyup w` (удерживать дольше EnterDuration).

**Ожидаемый результат:**
- После накопления `EnterDuration` (~1.33 с реального продвижения вперёд) происходит перенос.
- Фотография уничтожается, слот 0 освобождается.
- Игрок оказывается в запечатлённой точке с запечатлённым направлением взгляда.

**Верификация:**
- Консоль: `[Photo] Entered → teleported` → `[Player] Teleport → world=(…) yaw=… pitch=…`.
- После телепорта слот 0 в инвентаре **пуст** (предмет уничтожен).

**Автоматизация:** покрывается TC-F33-01 (JSON) — там в assertions проверяется и слот, и лог.

### TC-F31-06: Выброс активированной фотографии (Activated → InWorld)

**Покрытие:** F-31 (переход Activated → InWorld через drop) · **Тип:** логика

**Предусловия:** TC-F31-02 выполнен — фотография активирована. Инвентарь закрыт.

**Шаги:**
1. Открой инвентарь (`i`).
2. Выброс активированного: `1` (ряд 1), затем `Shift+1` (колонка 1 с Shift).
3. Закрой инвентарь (`i`).

**Ожидаемый результат:**
- Фотография выбрасывается из руки в мир (мягкая дуга `DropProjectile`).
- Слот 0 освобождается (бронь снята, предмет удалён из инвентаря).
- Живое окно исчезает, прогресс входа (если был) сброшен.
- Фотография в мире сохраняет запечатлённые данные.

**Верификация:**
- Консоль: `[Inventory] Drop 'photo' → world at (x, z)`.
- Отсутствие: **нет** `[Photo] Entered → teleported`.
- Визуал: фотография на полу; инвентарь — слот 0 пуст.

**Автоматизация:** не автоматизирован (требует модификатора Shift — не все раннеры его поддерживают; к тому же позиция падения зависит от направления взгляда).

### TC-F31-07: Выброс неактивированной фотографии (InInventory → InWorld)

**Покрытие:** F-31 (переход InInventory → InWorld) · **Тип:** логика

**Предусловия:** фотография в инвентаре (слот 0), не активирована. Инвентарь закрыт.

**Шаги:**
1. Открой инвентарь (`i`).
2. Установи курсор на слот 0 (`1` → `1`, затем любая другая ячейка — но без Shift), или используй `G` для выброса под курсором.
3. Или: `1` → `Shift+1` (выброс выбранной ячейки слот 0).

**Ожидаемый результат:**
- Фотография вылетает из инвентаря в мир (`DropProjectile` дуга).
- Слот 0 освобождён.
- Фотография в мире сохраняет запечатлённые данные.

**Верификация:**
- Консоль: `[Inventory] Drop 'photo' → world at (x, z)`.
- Визуал: предмет на полу, модель «фото-карточка».

**Автоматизация:** не автоматизирован (аналогично TC-F31-06).

### TC-F31-08: Подбор фотографии из мира (InWorld → InInventory)

**Покрытие:** F-31 (переход InWorld → InInventory, сохранность данных) · **Тип:** логика

**Предусловия:** фотография выброшена в мир (TC-F31-07). Инвентарь закрыт. Свободный слот есть.

**Шаги:**
1. Подойди к лежащей фотографии (используй миникарту / координаты из лога `[Inventory] Drop 'photo' → world at (x, z)`).
2. Подбор автоматический — просто сблизься на прямой (без стены между).

**Ожидаемый результат:**
- Фотография исчезает из мира и появляется в инвентаре в первом свободном слоте (вероятно, слот 0).
- Запечатлённые данные (позиция, yaw, pitch) **не изменились** — при последующей активации и входе игрок вернётся в ту же точку.

**Верификация:**
- Консоль: `[Inventory] Pickup 'photo' → slot N`.
- После подбора активируй и войди (TC-F31-05) — позиция телепорта та же, что была при создании.

**Автоматизация:** не автоматизирован (требует навигации игрока к WorldItem).
