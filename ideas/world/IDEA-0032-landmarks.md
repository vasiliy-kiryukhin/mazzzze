# IDEA-0032 — Ориентиры-«вини» над стенами

> **Область:** world · **Статус:** 🟡 идея

Высокий уникальный объект над линией стен (`WallHeight`=30) — сломанная башня, гигантская статуя, светящийся кристалл, столб дыма — виден из коридоров через полмаза и говорит «ты здесь» без HUD (диегетическая навигация, «weenie» по Диснею). Маяки: шахта света / цветное свечение / поднимающийся дым читаются даже когда сам объект скрыт стенами. Один стабильный ориентир у входа помогает переякориться при регенерации каждого запуска.

**Сложность:** 8 SP. **Ассеты:** Kenney (Graveyard/Fantasy), Quaternius, Poly Haven сканы, Sketchfab CC0 (статуи/руины) — все glTF, Godot-friendly.
