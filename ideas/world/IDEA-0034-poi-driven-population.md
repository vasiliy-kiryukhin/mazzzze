# IDEA-0034 — PoI-управляемое наполнение

> **Область:** world · **Статус:** 🟡 идея

Использовать точки интереса как якоря для лута, мобов, декора и ориентиров. Сейчас фасад даёт `RegionView.Pois` = `Entrance` / `Exit` / `DeadEnd`. Тупики — под спрятанную награду и мобов-стражей; вход/выход — под особый арт. Полезно завести новые PoI: **длинный прямой коридор** (простреливаемая сцена/засада), **junction** (≥3 связей — узел навигации), **зал** — их можно вывести game-side из `IsFloor`-соседства или через доработку фасада.

**Сложность:** 5 SP с существующими PoI (+3 если новые типы через façade work; `PoiKind` — закрытый enum).
